### 🔄 THE KEY INNOVATION: Guest Cart Merge

Problem: Guest adds items, then registers. Items disappear. ❌

Solution: Automatic merge on login ✅

Example Flow:
   1. Guest adds 5 items (stored in req.session.cart)
   2. Guest clicks "Register"
   3. User created in database (user_id = 5)
   4. Cart created (cart_id = 10)
   5. Items automatically transferred to database
   6. Guest session cart cleared
   7. Response: "5 items merged successfully!"
   8. User logs out and logs back in later
   9. Same 5 items still there (persisted!)

This is what makes the system special! 🌟

   5. Items still there from last time!

### 📞 TROUBLESHOOTING QUICK REFERENCE

Issue: "Cannot find module 'express-mysql-session'"
Fix: npm install express-mysql-session

Issue: "MySQL connection refused"
Fix: Start MySQL (mysql.server start or sudo service mysql start)

Issue: "No tables in database"
Fix: Run migrations:
   mysql -u root -p Shopsphere < database.sql
   mysql -u root -p Shopsphere < cart_and_sessions_setup.sql

Issue: "Sessions not persisting"
Fix: Check sessions table exists: USE Shopsphere; SHOW TABLES;

Issue: "Cart not merging on login"
Fix: Verify guest cart has items, user created, merge logic working
     See: TESTING_GUIDE.md Scenario 3

More help: See TROUBLESHOOTING sections in:
   • QUICK_START.md
